【开源】ZYPlayer 安卓影视聚合播放器 v1.0 发布
一款轻量、无广告、无会员的安卓影视聚合播放器。支持多源聚合搜索、在线播放、本地收藏、视频下载等功能。内置任何源，所有资源接口由用户自行添加，界面简洁、启动快速。

✨ 功能特性


🔍 多源聚合搜索

同时搜索全部已添加的源，边搜边展示，搜到 10 条立刻出结果
实时显示搜索进度（"正在搜索 36 个源…已返回 18 个"）
结果上限 100 条，支持"显示更多"


🎬 首页随机推荐

每次打开随机选取 3 个源、随机页拉取影片
每次刷新内容都不同，支持"换一批"
纯列表展示，加载极快


▶️ 视频播放

支持 m3u8 / mp4 直链 / WebView 解析页自适应播放
全屏/退出全屏一键切换（横屏沉浸式）
多线路自动识别


❤️ 本地收藏

一键收藏，本地持久化保存
独立"收藏"Tab，随时打开


⬇️ 视频下载

支持 MP4 直链下载（系统通知栏进度）
支持 m3u8 流媒体下载（自动合并分片、AES 解密）
前台服务后台下载，锁屏不中断
防重复下载


🔧 灵活的源管理

自定义添加/编辑/删除/开关资源接口
一键清空缓存
内置零源，完全由用户掌控
📱 隐私友好

无广告、无推送、无统计 SDK
无需注册登录，无任何账号体系

1. 安装 APK → 首次打开阅读并同意免责声明
2. 进入「设置」→ 添加源
3. 粘贴资源接口地址（苹果CMS格式），保存并启用
4. 回到首页 → 随机影片自动加载
5. 搜索、播放、收藏、下载


💡 资源接口格式示例：https://你的域名/api.php/provide/vod/
注：请使用源的json采集接口
